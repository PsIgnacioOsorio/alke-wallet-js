# 💳 Alke Wallet

Proyecto desarrollado para el Módulo 2 de Fundamentos de Desarrollo Front-End.

## Descripción

Alke Wallet es una billetera digital que permite simular la administración de fondos mediante una interfaz web. Los usuarios pueden iniciar sesión, realizar depósitos, enviar dinero a contactos y revisar el historial de movimientos.

## Funcionalidades

- Inicio de sesión con validación de credenciales.
- Visualización de saldo disponible.
- Realización de depósitos.
- Envío de dinero a contactos.
- Agregar nuevos contactos.
- Búsqueda de contactos.
- Historial de movimientos.
- Filtro de transacciones por tipo.
- Actualización dinámica de saldo y movimientos.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- jQuery
- LocalStorage
